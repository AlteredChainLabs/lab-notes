### MathLab restoration

Returned to MathLab, an experimental environment for learning mathematical
problem solving.

The existing prototype is built around a simple learning philosophy:

- problem solving is learned by doing
- writing helps thinking
- hints should guide rather than immediately reveal answers
- mathematical content should remain central
- the interface should stay simple

The core problem-solving experience currently includes a Work area, progressive
hints, gated solutions, an AI Tutor, problem tracks, and a content-driven
problem library.

The audit identified the hint ladder as the strongest existing pedagogical
mechanism.

The current AI Tutor, however, is only loosely connected to that learning
process. It receives the problem and the student's current work, but it does
not know which hints the learner has viewed, previous tutor interventions, or
the learner's current stage in the problem-solving process.

As a result, the current AI Tutor behaves more like a contextual mathematical
assistant than a true Socratic tutor.

## Product direction

The audit clarified the next direction for MathLab.

The goal is not to build a generic AI chatbot for solving mathematics.

Instead, MathLab should help a learner remain engaged in the problem-solving
process:

Problem
→ Think
→ Write
→ Ask for help when needed
→ Receive the smallest useful intervention
→ Try again
→ Make progress

The existing hint ladder provides a natural structure for this:

Nudge → Focus → Key Idea → Finish

The AI Tutor could eventually become a dynamic extension of this system,
choosing an appropriate intervention based on the problem, the learner's
written work, hints already viewed, and previous assistance.

Possible interventions include questions, examples, conceptual reminders,
misconception feedback, and progressively stronger hints.

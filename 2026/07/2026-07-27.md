## Work today

### MathLab AI Tutor restoration

Restored the MathLab AI tutoring pipeline after auditing the existing
production architecture.

The application uses Supabase for authentication and persistence, a Next.js
API route for tutor requests, and Ollama Cloud for model inference.

Two issues were identified:

- The Supabase project had been automatically paused after a period of inactivity.
- The previously configured `gemma3:4b` model had been retired by Ollama Cloud.

The Supabase backend was restored and the production model configuration was
updated to a currently supported Gemma 4 cloud model.

After redeployment, authentication and AI tutoring were successfully restored.

No application code changes were required for the initial restoration.
